Task Management Web Application

A responsive task management web application built to help users create, organize, and manage daily tasks efficiently. The application allows users to add, edit, and delete tasks while maintaining a clean and intuitive user interface.

==>Features
Add, edit, and delete tasks
Organized task workflow
Responsive user interface
Real-time task updates
Structured component-based architecture

==>Tech Stack
Angular
TypeScript
HTML5
SCSS / CSS3

 ==>Project Structure
Components for task creation and display
Modular Angular architecture
Configuration using TypeScript and Angular CLI
Maintainable and reusable UI elements

==>Installation & Setup
Clone the repository
git clone https://github.com/shahanaz-02/task_management

Navigate to project folder
cd task_management

Install dependencies
npm install

Run the application
ng serve

Open in browser
http://localhost:4200
